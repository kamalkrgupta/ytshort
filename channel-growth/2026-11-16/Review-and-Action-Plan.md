## 3. Test demonstration-led videos

For the next six new short videos, test a 25–40-second version where the lesson fits. This duration is an experiment, not a platform rule. Show a visible problem or finished result immediately, demonstrate one change, explain why it works and end with one useful action. Keep code readable on a phone and narration synchronized to the edit.

| Topic | First sentence / first frame | Demonstration | Closing action |
|---|---|---|---|
| CSS backgrounds | “Turn this plain card into a gradient.” Show before/after. | Change background to linear-gradient(135deg, #ffd6a5, #caffbf); explain direction and the two colors | “Try two colors and check the text stays readable.” |
| Button vs link | “Should this be a button or a link?” Show Submit and About. | Button submits a form; anchor navigates to another page | “Which would you use for a contact-page link?” |
| Class vs ID | “Style three cards with one CSS rule.” | Apply .card to repeated elements; show the resulting shared style | “Save the example for your next page.” |
| HTML images | “Your image is broken—check this path.” | Fix src and show the image appearing; briefly explain alt text | “Try fixing one broken image.” |
| CSS spacing | “Why did this card get bigger?” | Change padding, then margin; visibly contrast inside and outside space | “Which creates space inside the border?” |
| HTML forms | “Stop guessing what this input is for.” | Add a label with matching for/id; show clicking the label focusing the field | “Add a label to one input today.” |

Remove filler such as “keep this detail in mind” when a concrete explanation can replace it. Do not pad a short lesson to a fixed 60-second renderer. Update scene timings and inspect the completed render before upload. Preserve original files and existing scheduled lessons while preparing new versions.

## 4. YouTube packaging and course navigation

Keep the already-established course playlists and Start Here navigation; verify their live state after reconnecting. Group AI, coding and testing clearly so a new viewer can choose one learning path.

Use outcome-led, accurate titles for new uploads: “Fix a Broken HTML Image: src and alt Explained”, “CSS Padding vs Margin: See the Difference”, or “Button vs Link in HTML: Which Should You Use?” Existing descriptive titles need not be changed merely to match this pattern.

For long tutorials, make the thumbnail promise specific and deliver it early in the video. Review the six Agile packaging experiments before replacing those thumbnails again. Short-feed discovery should be evaluated through feed exposure, stayed-to-watch and retention; long-video packaging should be assessed using eligible impressions and CTR alongside viewing quality. Do not combine the formats into one performance comparison.

## 5. Fourteen-day test and decision rules

Start the measurement period when access and publication are verified; suggested window November 17–30. Keep the existing cadence as a starting point, without increasing volume. No evidence currently establishes that 19:00 IST is the best audience time.

Record each new upload at 24 hours and seven days. Use the accompanying CSV, leaving unavailable values blank. Record historical videos separately so lifetime totals are not compared with first-day results.

- YouTube Shorts: engaged views, stayed-to-watch, average watch duration, average percentage viewed, subscribers gained and meaningful comments.
- YouTube longer lessons: impressions, CTR, watch duration, retention near the opening, watch time, traffic sources and subscribers gained.
- Instagram: views, unique accounts reached, non-follower reach, average watch duration, saves, shares and follows attributed to each Reel when shown.

Within comparable topic/length groups, compare the median seven-day results of the next six demonstration-led uploads with recent comparable uploads. This is directional evidence, not a randomized causal test. With little exposure, record “inconclusive” rather than declaring a winner.

If Shorts attract exposure but viewers swipe away, test the opening frame and sentence. If viewers stay initially but leave during explanations, shorten filler and bring the payoff forward. If long videos have weak CTR relative to comparable channel videos, test packaging; if CTR is reasonable but early retention drops, improve delivery of the promise. For Instagram, compare shares/reach and saves/reach only when reach is available and denominators are meaningful.

If Trial Reels is available in the app, consider testing one new creative format with non-followers before sharing broadly. This feature is optional; nothing was published or configured in this review.
