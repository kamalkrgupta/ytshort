# Next production: make the useful result visible immediately

These are production briefs for the next planned web projects, not replacement uploads. Existing published video media and release times have not changed. Do not duplicate an upload if a receipt already exists.

## 47 — Build a Personal Profile Card

Title: Build a Profile Card with HTML and CSS

Opening: “Build this profile card with a name, bio and link.” Show the finished card immediately.

Demonstration: reveal the small HTML structure, add padding and a border radius, then style the link. Narrate the exact property changing on screen. Keep code large enough to read on a phone.

Ending: “Change the name and colors to make it yours.” Use one clear action instead of a list of requests.

## 48 — Build a Responsive Navigation Bar

Title: Responsive Navbar with HTML and CSS: Phone to Desktop

Opening: “These links need to fit on a phone.” Show the same navigation at narrow and wide widths.

Demonstration: start with the narrow layout; introduce the layout rule and breakpoint used by the example. Resize the preview so the viewer sees the change.

Ending: “Try a narrower screen—can you still use every link?”

## 49 — Build a JavaScript Counter

Title: Build a JavaScript Counter: Click to Add One

Opening: “One click, one number higher. Here is how.” Show the working button and counter before the code.

Demonstration: show state, select the display and button, add a click listener, then update textContent. Keep each line visible long enough to read. Make the state-to-screen relationship explicit.

Ending: “Can you add a reset button?”

## 50 — Build a Simple To-Do List

Title: Build a Simple JavaScript To-Do List

Opening: “Type a task. Click Add. It appears in the list.” Show the working example.

Demonstration: show the input value, create the list item using textContent and append it. Include whatever empty-input behavior the example actually implements. Avoid implying persistence unless it is taught.

Ending: “Try adding one task of your own.”

## 51 — Publish Your First Website for Free

Title: Publish Your First Website: A Beginner Walkthrough

Opening: “Your page works on your computer. Now put it online.” Show the final public URL and page with personal information removed.

Demonstration: use a currently verified hosting flow, show the required files and actual deployment result. Verify current free-plan availability before promising free hosting. If the full flow cannot be taught clearly in a Short, make a concise preview linked through YouTube Studio's Related video control to a complete walkthrough.

Ending: “Open your link on a phone and check it works.”

## Production checks

Use the length the actual demonstration needs; do not force a short script into a fixed-length render. Check voice timing, pronunciation, readable code, visual accuracy and dead air in the completed media. Avoid a long branded intro. A silent result slide with generic narration does not demonstrate a working interaction.

For Shorts, ordinary description URLs are not clickable. The Related video feature is a Studio action and was not configured through the current API workflow. Use it only for a relevant, confirmed public lesson. Keep thumbnail/title promises accurate.

After publishing, compare each video's first 24 hours and first seven days with similar videos. Use Shorts engaged views, stayed-to-watch and retention from Studio; lifetime public views alone cannot diagnose the opening.
